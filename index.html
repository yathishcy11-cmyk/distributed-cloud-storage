ENGINEERING FEATURES

What this project demonstrates

01

Chunking

Large files are split into fixed-size 5 MB chunks for parallel processing.

02

Replication

Every chunk is placed on multiple storage nodes to survive a node failure.

03

Integrity

SHA-256 checksums verify that reconstructed data matches the original upload.

04

Recovery

Missing replicas are detected and re-created on healthy nodes.
